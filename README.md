## 🌍 Подорожники

Багатосторінковий вебсайт для мандрівників, де можна ділитися власними історіями подорожей, читати історії інших та зберігати найцікавіші до свого профілю.

🔗 Демо: [https://travel-stories-frontend.vercel.app/]
🔗 Бекенд: [https://travel-stories-backend.onrender.com/]

## 📖 Про проєкт

Подорожники — це платформа-спільнота для людей, які живуть подорожами.

Проєкт вирішує наступні задачі:
Дає мандрівникам місце, де можна опублікувати власну історію подорожі;
допомагає знаходити натхнення: популярні історії, добірки за категоріями, профілі інших мандрівників;
дозволяє зберігати сподобані історії в особистий профіль, щоб повернутися до них пізніше.

Основні можливості
Реєстрація та вхід користувача
Перегляд списку історій із серверною пагінацією
Сторінка окремої історії з деталями та блоком популярних історій
Список мандрівників та публічний профіль мандрівника
Додавання/видалення історій у збережені (для неавторизованих — модальне вікно AuthNavModal)
Особистий профіль із вкладками «Збережені історії» та «Мої історії»
Створення та редагування власних історій (завантаження обкладинки, категорія, текст)
Адаптивна верстка (mobile-first), бургер-меню на мобільних пристроях

## 🛠 Технології

Фреймворк Next.js (App Router), React
TypeScript
CSS Modules, modern-normalize
Zustand
Робота з даними TanStack Query (React Query)
Форми та валідація Formik, Yup
Зображення next/image
Форматування коду Prettier

За замовчуванням використовуються Server Components;
Client Components — лише там, де потрібні інтерактивність, форми, React Query чи Zustand.
Для сторінок історій та авторів підключено generateMetadata та OG-теги.
Глобальні error.tsx та not-found.tsx розміщені в корені app.
Стилі написані за підходом Mobile First з медіа-функцією min-width.
Адаптивність
Mobile гумова верстка від 320px, адаптивна з 375px
Tablet від 768px
Desktop від 1440px

## 🗺 Структура сторінок

Сторінка Маршрут
Головна /
Реєстрація /auth/register
Вхід /auth/login
Історії /stories
Історія /stories/[storyId]
Створення історії /stories/create
Редагування історії /stories/[storyId]/edit
Мандрівники /travellers
Публічний профіль мандрівника /travellers/[travellerId]
Профіль (збережені / мої історії) /profile, /profile/saved, /profile/own
